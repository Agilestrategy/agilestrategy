    For the office — how to collect the data

    Every submission can reach you five ways. Pick whatever suits:

    1. Straight into a spreadsheet (best). Set CLUB.endpoint in the code to a Google Sheets Apps Script web-app URL (or a Formspree/Sheety endpoint). Each submission then posts itself as a new row automatically — nothing to do.
    2. Download CSV — one row with a fixed column order; open it and append to the master members spreadsheet.
    3. Download JSON — full structured record for any system.
    4. Copy data row — paste a tab-separated row straight into the spreadsheet.
    5. Email the office — opens an email to with the details.

    Pre-filling for renewals: send members a link with their details in the URL, e.g. ?mode=Renewal&memberNumber=1234&fullName=Jane%20Doe&email=jane@x.nz&membershipType=Senior. Any field name works as a parameter; the form fills itself in. After a submission you can also hit Copy renewal link to grab a ready-made link for next year.
