Platform quick reference

Every link, one page

Educating Empowering and Enabling · updated 4 September 2026 · live on forms.agilestrategy.co.nz
Publishing, in three steps. The site is linked to GitHub: whatever is in the repo's public folder on main IS the website. Netlify deploys it automatically.
  1. Open github.com/Agilestrategy/agilestrategy/tree/main/public (the breadcrumb must read agilestrategy / public).
  2. Add file → Upload files, drop the changed pages, Commit changes directly to main.
  3. Wait ~1 minute for the deploy, hard refresh, then work down this page ticking as you go.
THE TRAP: files uploaded to the repo root never reach the site. The breadcrumb is the tell — if it says just "agilestrategy", you are in the wrong place. (The "Public" badge next to the repo name is visibility, not the folder.) And never rename the Netlify project: the custom domain below survives a rename, nothing else does.
